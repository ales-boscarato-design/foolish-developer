### Task 2: Canonical + noindex filtrato su `/recensioni`

**Files:**
- Modify: `storefront/src/app/[locale]/recensioni/page.tsx`

Senza canonical, Google vede `/recensioni?prodotto=x&stelle=5` come pagine distinte con duplicate content. Con i filtri attivi va noindex; senza filtri va canonical + hreflang.

- [ ] **Step 1: Aggiungere import e generateMetadata**

```tsx
// storefront/src/app/[locale]/recensioni/page.tsx
// Aggiungere in cima al file, dopo gli import esistenti:
import type { Metadata } from 'next'

const BASE = 'https://thefoolishbutcher.com'
const LOCALES = ['it', 'en', 'fr', 'es', 'de'] as const

interface Props {
  searchParams: Promise<{ prodotto?: string; stelle?: string }>
}

export async function generateMetadata({
  params,
  searchParams,
}: {
  params: Promise<{ locale: string }>
  searchParams: Promise<{ prodotto?: string; stelle?: string }>
}): Promise<Metadata> {
  const { locale } = await params
  const { prodotto, stelle } = await searchParams
  const isFiltered = !!(prodotto || stelle)
  const langs = Object.fromEntries(LOCALES.map(l => [l, `${BASE}/${l}/recensioni`]))
  return {
    title: locale === 'it' ? 'Recensioni — The Foolish Butcher' : 'Reviews — The Foolish Butcher',
    description:
      locale === 'it'
        ? 'Recensioni verificate da acquirenti reali di pelle sintetica per tattoo e PMU.'
        : 'Verified reviews from real buyers of synthetic tattoo and PMU practice skin.',
    robots: isFiltered ? { index: false, follow: false } : { index: true, follow: true },
    alternates: isFiltered
      ? undefined
      : {
          canonical: `${BASE}/${locale}/recensioni`,
          languages: { ...langs, 'x-default': `${BASE}/it/recensioni` },
        },
  }
}
```

Nota: l'interfaccia `Props` esistente (riga 8 dell'originale) va rimossa perché viene ridefinita qui sopra. Assicurarsi che il `default export` usi la firma `({ searchParams }: Props)` invariata.
